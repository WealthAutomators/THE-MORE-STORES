# THE MORE STORES

A bold contemporary ecommerce storefront for THE MORE STORES — a modern digital department store marketplace.

Built on a reusable Next.js ecommerce engine (cart, wishlist, search, filters, checkout demo) with a unique color-blocked UI.

## Tech Stack

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **shadcn/ui** (Radix primitives)
- **Lucide Icons**
- **Framer Motion**
- **Embla Carousel**
- **React Context** (cart, wishlist, recently viewed)
- **localStorage** persistence (no backend)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # Production build
npm run start   # Start production server
```
